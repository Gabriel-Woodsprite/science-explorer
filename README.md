# SCIENCE EXPLORER

**Science Explorer** es una aplicación web educativa enfocada en la exploración de la ciencia, la computación y la inteligencia artificial. Su objetivo es ofrecer una experiencia interactiva que facilite el aprendizaje mediante información, experimentos virtuales, actividades y desafíos científicos.

## Funcionalidades

La aplicación cuenta con las siguientes secciones y funcionalidades:

- **Inicio (`#inicio`):** Presentación de la aplicación y accesos directos a sus principales secciones.
- **Biblioteca de descubrimientos (`#descubrimientos`):** Consulta y filtrado de 30 fichas informativas sobre descubrimientos científicos.
- **Grandes científicos (`#cientificos`):** Biografías de científicos destacados y descripción de sus principales contribuciones.
- **Laboratorio interactivo (`#laboratorio`):** Tres simulaciones educativas para explorar y comprender diferentes fenómenos científicos.
- **Línea del tiempo (`#cronologia`):** Exploración cronológica de acontecimientos e hitos importantes de la ciencia.
- **Desafío científico (`#desafio`):** Cuestionario interactivo con evaluación y calificación de los conocimientos adquiridos.
- **Mi bitácora científica (`#bitacora`):** Espacio personal para guardar descubrimientos favoritos y registrar notas.

## Ejecución local

Para ejecutar el proyecto en tu equipo, sigue estos pasos:

### 1. Clonar el repositorio

Abre una terminal y ejecuta el siguiente comando:

```bash
git clone https://github.com/Gabriel-Woodsprite/science-explorer.git
```

### 2. Abrir el proyecto

Accede a la carpeta del proyecto:

```bash
cd science-explorer
```

### 3. Ejecutar la aplicación

Abre el archivo `index.html` directamente en tu navegador web.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para ejecutar el proyecto mediante un servidor de desarrollo local.
